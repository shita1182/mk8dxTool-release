# マリカツール（配布用）

マリオカート8DXの配信用ツールの配布ページです。ダウンロードは [Releases](https://github.com/shita1182/mk8dxTool-release/releases/latest) から。

このツールは、登録した人だけが使えます（初めて起動したときに利用登録をします。下の「利用登録」）。

## はじめて使うとき（Windows）
1. [最新の版](https://github.com/shita1182/mk8dxTool-release/releases/latest) から `marikaTool-windows.zip` をダウンロードする
2. 好きなフォルダに展開する
3. タイマーを使う場合は、[timer.mp4](https://github.com/shita1182/mk8dxTool-release/releases/download/v1.0.0/timer.mp4) をダウンロードして、展開したフォルダの `timer` フォルダに入れる（約810MB。zip には入っていません）
4. `marikaTool.exe` を起動する（インストールは要りません）
5. 利用登録をする（下の「利用登録」）

## はじめて使うとき（mac）
1. [最新の版](https://github.com/shita1182/mk8dxTool-release/releases/latest) から `marikaTool-mac.zip` をダウンロードして展開する
2. `marikaTool.app` を「アプリケーション」フォルダ（または好きなフォルダ）にドラッグして入れる
3. 初めて開くときは、`marikaTool.app` を右クリック →「開く」
   - 「開けません」と出たときは、「システム設定」→「プライバシーとセキュリティ」の下の方にある「このまま開く」を押す
   - 「書類」フォルダへのアクセスを聞かれたら許可する
4. 利用登録をする（下の「利用登録」）
5. 戦績・設定などは「書類」の中の「マリカツール」フォルダに置かれます
   - タイマーを使う場合は、[timer.mp4](https://github.com/shita1182/mk8dxTool-release/releases/download/v1.0.0/timer.mp4) をダウンロードして、「マリカツール」フォルダの中の `timer` フォルダに入れる
6. 初めて「開始」を押したときに「カメラへのアクセス」を聞かれるので、許可する

## 利用登録
1. 初めて起動すると「利用登録」の画面が出るので、ユーザー名を入れて「申請する」を押す
2. 管理者からコードを受け取ったら、その画面に入れて「確認する」を押す（一度入れれば、次からは聞かれません）

- 名前を送っただけで閉じたときは、次に起動したときはコードの入力から始まります
- ユーザー名は、フレンドの記録や今月の課題の順位でほかの人に見えます

使い方（OBSの設定など）は、ツールの左のメニュー「使い方」に載っています。

## アップデート
起動したときに新しい版があれば知らせます（「設定」→「更新を確認」でも確認できます）。
「はい」を押すと、ダウンロードしてツールを閉じ、入れ替えて起動し直します。戦績・設定・タイマーの動画はそのまま残ります。

- **v1.2.0 以前の版を使っている場合**：自動アップデートの入れ替えに失敗するので、一度だけ手で入れ替えてください。
  ツールを閉じてから、最新の zip の中身をツールのフォルダに上書きします（mac は `marikaTool.app` を入れ替えます）。戦績・設定はそのまま残ります
- アップデートのあと「Failed to load Python DLL」と出たときは、もう一度ツールを起動してください（入れ替えはできています。v1.2.3 で直りました）

## 困ったとき
- ツールの左のメニュー「使い方」の「困ったとき」を見てください
- 起動しない・すぐ閉じるときは、ツールのフォルダ（mac は「書類」→「マリカツール」）の `marikaTool_error.log` にエラーの内容が残ります。管理者に見せてください
