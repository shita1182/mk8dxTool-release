# マリカツール（配布用）

マリオカート8DXの配信用ツールの配布ページです。ダウンロードは [Releases](https://github.com/shita1182/mk8dxTool-release/releases/latest) から。

## はじめて使うとき（Windows）
1. [最新の版](https://github.com/shita1182/mk8dxTool-release/releases/latest) から `marikaTool-windows.zip` をダウンロードする
2. 好きなフォルダに展開する
3. タイマーを使う場合は、v1.0.0 のページから `timer.mp4` をダウンロードして、展開したフォルダの `timer` フォルダに入れる
4. `marikaTool.exe` を起動する

## はじめて使うとき（mac）
1. [最新の版](https://github.com/shita1182/mk8dxTool-release/releases/latest) から `marikaTool-mac.zip` をダウンロードして展開する
2. `marikaTool.app` を「アプリケーション」フォルダ（または好きなフォルダ）にドラッグして入れる
3. 初めて開くときは、`marikaTool.app` を右クリック →「開く」
   - 「開けません」と出たときは、「システム設定」→「プライバシーとセキュリティ」の下の方にある「このまま開く」を押す
4. 戦績・設定などは「書類」の中の「マリカツール」フォルダに置かれます
   - タイマーを使う場合は、v1.0.0 のページから `timer.mp4` をダウンロードして、「マリカツール」フォルダの中の `timer` フォルダに入れる

使い方は、ツールの左のメニュー「使い方」に載っています。

## アップデート
起動したときに新しい版があれば知らせます（「設定」→「更新を確認」でも確認できます）。
「はい」を押すと、ダウンロードしてツールを閉じ、入れ替えて起動し直します。戦績・設定・タイマーの動画はそのまま残ります。
